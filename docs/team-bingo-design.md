# 팀 빙고 설계

> 2026-08-13 확정. `/grill-me` 세션 결과.

## 원칙

경쟁 앱도 응원 앱도 아니다. **자기 목표를 이루는 데 동기부여 장치를 얹는 것.**
설계상 애매한 지점은 이 기준으로 판단한다.

## 진입 플로우

```
홈 · 새 빙고 만들기
├ 나만의 빙고
└ 친구와 같이하기
   ├ 같이 채우기        빙고판 하나를 친구들과 나눠서 완성해요
   └ 각자 채우기
      ├ 같은 목표로     같은 목표로 시작해 각자 자기 판을 채워요
      └ 다른 목표로     서로 다른 목표를 세우고 대결해요
```

기존 빙고 카드의 대결 아이콘은 **유지하되 역할 변경** — 팀 빙고에만 표시되는
상태 표시 + 팀 현황 이동 전용. 개인 빙고를 팀으로 전환하는 경로는 없다.

## 3개 모드

|           | 같이 채우기 `shared`         | 같은 목표로 `copied`  | 다른 목표로 `own`     |
| --------- | ---------------------------- | --------------------- | --------------------- |
| 판        | 1개 공유                     | 각자 복사본           | 각자 자유 작성        |
| 내용 수정 | 방장만, `max_edits`까지      | 각자, `max_edits`까지 | 각자, `max_edits`까지 |
| 완료된 칸 | 내용 수정 불가               | 내용 수정 불가        | 내용 수정 불가        |
| 순위      | 없음 (팀 진행률 + 개인 기여) | 달성률 순             | 달성률 순             |
| 왕관      | 없음                         | 1등 (동률 공동)       | 1등 (동률 공동)       |
| 내기      | 없음                         | 없음                  | 있음                  |
| 인원      | 방장 포함 최대 6명           | 동일                  | 동일                  |

## 데이터 모델

```
team_bingos    id, owner_id, title, mode, start_date, end_date, bet_text,
               status(waiting/in_progress/completed), completed_at

team_members   team_id, user_id, board_id(nullable), status(invited/joined/left),
               achieved_count, total_count, bingo_count, final_rank

bingo_cells    + completed_by       -- 누가 채웠는지
               + memo_updated_by    -- 메모 마지막 수정자
```

- 기존 `battles` / `battle_requests`는 **drop**. 초대·수락·순위·종료 로직을 두 벌 유지하지 않는다.
- `shared` 모드 판은 `bingo_boards.user_id = 방장` 1행. 소유 컬럼은 그대로 두고
  **RLS를 멤버십 기준으로 확장**해 6명 모두의 홈에 자기 빙고처럼 노출한다.
- 방장 이탈 시 `owner_id`(및 `shared` 판의 `user_id`)를 남은 멤버 중 아이디순 첫 번째로 이양한다.
- `battle_requests`가 강제하던 **"친구 사이만 초대 가능"** 규칙을 새 초대 경로에 이식한다.

## 권한

- 체크 해제는 **체크한 본인만**.
- 메모는 **전원 편집 가능**, 마지막 수정자를 표기한다.
- `shared` 셀 UPDATE에 `is_checked = false` 조건을 걸어 동시 체크는 먼저 누른 쪽이 이긴다.
  진 쪽에는 "이미 OO님이 채웠어요" 안내 후 화면을 갱신한다.
- 갱신은 **진입 시 + 당겨서 새로고침**. Realtime은 도입하지 않는다.
- `max_edits`를 **팀 빙고에 한해 DB 트리거로 강제**한다. 개인 빙고는 현행 유지.
- 팀 빙고의 `checked_at` 선택 범위를 **기간 내로 제한**한다.

## 생명주기

1. 방장이 기간(시작일 직접 선택 + 프리셋/직접 지정)과 내용을 정하고 친구를 최대 5명 초대한다.
2. **시작일 전까지 `waiting`** — 수락은 되지만 체크 불가. "N일 후 시작해요".
3. 수락한 사람부터 참여한다. **초대장은 기간 종료까지 유효**하고, 늦게 수락하면 남은 기간만
   참여한다(수락 화면에 "기간이 N일 남았어요" 표시). 수락 전에는 팀원이 아니다.
4. `copied` / `own`은 **수락 = 판 생성**이다. 기간은 고정이고 제목·칸·테마만 입력해야 참여가 확정된다.
   `own`은 내용 자유, `copied`는 방장 판의 복사본.
5. 종료는 클라이언트 지연 확정 + **freeze 트리거**. 순위는 **달성률(`채운 칸 / 전체 칸`)** 기준이며
   빙고 줄은 표시만 한다. 동률은 공동 1등, 정렬은 빙고 줄 → `first_checked_at` 순.
6. 이탈 시 채운 칸은 **그대로 유지**하고(`completed_by`만 탈퇴 표기), 각자 판은
   **개인 빙고로 전환되어 본인에게 남는다**. 혼자 남아도 팀은 유지된다.

## 화면

- **팀 현황**: 프로필을 왼쪽→오른쪽 1등~꼴등으로 원형 나열, 1등에 왕관.
  `shared`는 상단에 팀 전체 진행률, 하단에 개인 기여 수.
- **홈 카드**: 겹친 아바타로 팀 표시 (`features/battle/components/BattleListItem.tsx:44-58` 재사용).
- 회고는 **멤버별 개인 회고**(별도 테이블).
- 커뮤니티 공유는 각자 자유. `shared` 판 스냅샷은 완료자 프로필을 가려서 게시한다.

## 알림

`team_invite`, `team_joined`, `team_finished`, 그리고 **칸 체크마다 전 모드·본인 제외 전원**.
`notification_settings.team_activity` 토글을 추가한다(기본 ON).

## 함께 고친 기존 버그 (모두 반영됨)

1. **3개 제한 부활** — `check_bingo_board_limit()`가 존재하지 않는 `status='active'`를 세고 있어
   사실상 무제한이었다. `status='progress' AND deleted_at IS NULL`로 고치고
   **팀 참여도 1칸으로 계산**한다.
2. **`createBingo` 롤백이 조용히 실패** — `bingo_boards`에 DELETE 정책이 없어 고아 판이
   영구히 슬롯을 점유한다. 제한이 살아나는 순간 "빙고를 못 만들어요"로 터진다.
   → `create_bingo_with_cells` RPC로 원자화했다.
3. **`max_edits` 의미 반전** — DB 주석은 `0=무제한`, 클라이언트는 `0=수정불가` / `9999=무제한`.
   → 컬럼 주석을 클라이언트 의미로 통일했다.
